# Load-Aware Quadruped Navigation with Online Contact-based Geometry Estimation — project page

Live site (after deploy): **https://qiii04.github.io/LOADNav/**

## Deploy (one time)

```bash
# 1. Create an empty public repo named `LOADNav` at https://github.com/new
# 2. From inside this folder:
git init
git add .
git commit -m "Project website"
git branch -M main
git remote add origin https://github.com/qiii04/LOADNav.git
git push -u origin main
# 3. On GitHub: Settings → Pages → Source: "Deploy from a branch" → main / (root) → Save
```

The page goes live at https://qiii04.github.io/LOADNav/ within a minute or two.
(If you prefer a different repo name, just change `LOADNav` in the URL, in the `Code` button
and in the `og:image` meta tag of `index.html`.)
